# আল-ফিকহ অ্যান্ড ইসলামিক স্টাডিজ ডিজিটাল লাইব্রেরি

## যোগ করা শিক্ষার্থী ফিচার
- কোর্স পাতা খুললে বইয়ের তালিকা প্রথমে দেখা যায়; এরপর সিলেবাস ও মানবণ্টন। কাস্টম প্রিন্ট থেকে তিনটি অংশের যেকোনো সমন্বয় বেছে নেওয়া যায়।
- সিলেবাসের প্রতিটি তালিকাভুক্ত বিষয় টিক দিয়ে অগ্রগতি রাখা যায়।
- বই পরে পড়ার তালিকায়, কোর্স ও বইয়ের শেয়ার লিংক, ব্যক্তিগত কোর্স নোট/রিসোর্স, সাপ্তাহিক রুটিন, রেটিং ও রিভিউ রাখা যায়।
- অভিধান পাতায় আরবি, বাংলা, ইংরেজি ও উর্দুর বহিরাগত অভিধান/রেফারেন্স অনুসন্ধান রয়েছে। আরবি ক্লাসিক্যাল অভিধানের পাঁচটি Shamela-লক্ষ্যিত অনুসন্ধানও আছে। Shamela মূলত আরবি ঐতিহ্যবাহী গ্রন্থাগার; বাংলা বা ইংরেজি অভিধান সেখানে আছে বলে দাবি করা হয়নি।
- কুরআন সার্চ Quranic Arabic Corpus-এ এবং হাদিস সার্চ Sunnah.com-এ খোলে।
- তুলনামূলক ফিকহ অংশে Shamela-র الموسوعة الفقهية الكويتية PDF লিংক রয়েছে।
- PWA shell ও ডেটা অফলাইনে ক্যাশ হয়। বাহ্যিক PDF/অভিধান/সার্চের জন্য ইন্টারনেট দরকার।

## নোটিশ যোগ করা
`site.js`-এর `NOTICES` অ্যারেতে এই আকারে একটি এন্ট্রি যোগ করে GitHub Pages-এ পরিবর্তন প্রকাশ করুন:

```js
{id:1,date:"2026-11-01",bn:{t:"নোটিশের শিরোনাম",b:"নোটিশের বিস্তারিত"},ar:{t:"عنوان الإعلان",b:"تفاصيل الإعلان"}}
```

প্রতিটি নতুন নোটিশের `id` আগের চেয়ে বড় দিন। ব্রাউজার নোটিফিকেশন ব্যবহারকারীর অনুমতি ও সাইট/অ্যাপ আবার খোলার ওপর নির্ভরশীল। বন্ধ থাকা অবস্থায় push notification পাঠাতে আলাদা push server/service লাগবে।

## ব্যক্তিগত তথ্য
বুকমার্ক, পরে পড়া, অগ্রগতি, নোট, রুটিন এবং রিভিউ বর্তমানে ব্যবহারকারীর নিজস্ব ব্রাউজারের `localStorage`-এ থাকে। এগুলো অন্য ডিভাইসে সিঙ্ক হয় না। একাধিক ডিভাইসে অ্যাকাউন্ট, সবার দেখা রেটিং/রিভিউ, বা আলোচনা ফোরাম চালাতে authentication ও backend/database দরকার হবে। সেটিংস থেকে এই ব্রাউজারের ব্যক্তিগত সংরক্ষিত তথ্য মুছতে পারবেন।
