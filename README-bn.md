# আল-ফিকহ অ্যান্ড ইসলামিক স্টাডিজ ডিজিটাল লাইব্রেরি

## যোগ করা শিক্ষার্থী ফিচার
- কোর্স পাতা খুললে বইয়ের তালিকা প্রথমে দেখা যায়; এরপর সিলেবাস ও মানবণ্টন। কাস্টম প্রিন্ট থেকে তিনটি অংশের যেকোনো সমন্বয় বেছে নেওয়া যায়।
- সিলেবাসের প্রতিটি তালিকাভুক্ত বিষয় টিক দিয়ে অগ্রগতি রাখা যায়।
- বই পরে পড়ার তালিকায়, কোর্স ও বইয়ের শেয়ার লিংক, ব্যক্তিগত কোর্স নোট/রিসোর্স, সাপ্তাহিক রুটিন, রেটিং ও রিভিউ রাখা যায়।
- রুটিনে শিক্ষার্থীর বর্ষ জানা থাকলে সেই বর্ষ বেছে কোর্স কোড ও নাম দেখা যায়; বর্ষ সংরক্ষিত না থাকলে সব বর্ষের কোর্স কোড ও নামসহ তালিকায় আসে। এই স্ট্যাটিক সংস্করণে বর্ষটি ব্রাউজারে রাখা হয়; সার্ভার ডেটাবেসে যুক্ত নয়।
- অভিধান পাতায় আরবি/বাংলা/ইংরেজি লিপি শনাক্ত করে যথাক্রমে Almaany, সরকারি Accessible Dictionary বা Cambridge-এর নির্দিষ্ট শব্দ-পেজে পাঠায়।
- কুরআন সার্চ Quranic Arabic Corpus-এ এবং হাদিস সার্চ Sunnah.com-এ খোলে।
- PWA shell ও ডেটা অফলাইনে ক্যাশ হয়। বাহ্যিক PDF/অভিধান/সার্চের জন্য ইন্টারনেট দরকার।

## নোটিশ যোগ করা
`site.js`-এর `NOTICES` অ্যারেতে এই আকারে একটি এন্ট্রি যোগ করে GitHub Pages-এ পরিবর্তন প্রকাশ করুন:

```js
{id:1,date:"2026-11-01",bn:{t:"নোটিশের শিরোনাম",b:"নোটিশের বিস্তারিত"},ar:{t:"عنوان الإعلان",b:"تفاصيل الإعلان"}}
```

প্রতিটি নতুন নোটিশের `id` আগের চেয়ে বড় দিন। ব্রাউজার নোটিফিকেশন ব্যবহারকারীর অনুমতি ও সাইট/অ্যাপ আবার খোলার ওপর নির্ভরশীল। বন্ধ থাকা অবস্থায় push notification পাঠাতে আলাদা push server/service লাগবে।

## ব্যক্তিগত তথ্য ও সর্বজনীন রিভিউ
বুকমার্ক, পরে পড়া, অগ্রগতি, নোট ও রুটিন ব্যবহারকারীর ব্রাউজারে থাকে। কোর্স রেটিং/রিভিউ সবার দেখার জন্য Supabase backend সংযোগ প্রস্তুত করা হয়েছে।

1. Supabase project-এর SQL Editor-এ `reviews-setup.sql` চালান।
2. `site.js`-এ `SITE.reviews.url`-এ Project URL এবং `SITE.reviews.anonKey`-এ publishable/anon key বসান। `service_role` বা secret key কখনো এই ওয়েবসাইটে বসাবেন না।
3. GitHub Pages-এ প্রকাশ করুন। তারপর কোর্স পাতায় নতুন ও আগের রিভিউ এবং গড় রেটিং সবাই দেখতে পাবে।

রিভিউ সর্বজনীন হবে, তাই নাম, ফোন, ইমেইল বা ব্যক্তিগত তথ্য না দিতে ব্যবহারকারীকে বলা হয়েছে। Anonymous পোস্টে স্প্যাম ঠেকাতে Supabase-এ অতিরিক্ত moderation বা rate limiting যোগ করা যেতে পারে। সেটিংস থেকে ব্যক্তিগত ব্রাউজার-ডেটা মুছলেও প্রকাশিত রিভিউ ডেটাবেসে থাকবে।
